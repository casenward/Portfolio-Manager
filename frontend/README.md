# Portfolio Dashboard (frontend)

Vite + React UI for total worth, sector allocation, and company holdings.
Data comes from the backend `GET /dashboard` endpoint (proxied via `/api` in dev).

## Setup

```bash
npm install
```

## Run

Start the API first (`cd backend && python main.py`), then:

```bash
npm run dev
```

Open [http://127.0.0.1:5173](http://127.0.0.1:5173).
